# 위키백과 검색이 주제와 무관한 문서를 함께 돌려준다

## 증상

주제 제목으로 위키백과 전문 검색을 하면 본문에 낱말이 들어갔다는 이유만으로
관련 없는 문서가 섞여 나온다.

## 확인한 것

주제 "스크럼 회고"로 실제 검색한 결과 (http://localhost:3000, 로컬 dev 서버):

1. 스크럼 (프로젝트 관리) — 적절
2. 플레이밍 스타 — 엘비스 프레슬리 영화. 본문에 "회고"가 있어 걸림
3. 엘비스 프레슬리 — 같은 이유

주제 "기술 부채 정리"는 세 건 모두 무관했다.

1. 대한민국 — "부채"가 국가 부채로 걸림
2. 남해회사 — 18세기 금융 사건
3. 뱅크런

## 짐작하는 원인

`action=query&list=search`는 제목이 아니라 본문 전체를 훑는다. 여러 낱말로 된
주제 제목을 그대로 넘기면 각 낱말이 흩어져 들어간 문서가 함께 잡힌다.

## 지금 해 둔 것

자료 목록 위에 "위키백과에서 찾은 문서입니다. 주제와 상관없는 것이 섞일 수
있습니다."라고 밝혀 참석자가 걸러 보게 했다. 출처의 한계 자체는 그대로다.

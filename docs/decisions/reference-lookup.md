# 배경 자료 찾기

## Decisions

- 위키백과에서 자료를 찾을 때 본문을 훑는 전문 검색(`list=search`)을 쓰지 않고
  제목으로 찾는다(`generator=prefixsearch`).
- 주제 하나에 문서 하나만 붙인다.
- 제목이 맞는 문서가 없으면 아무것도 붙이지 않고 없다고 알린다.
- 요약은 문서 첫 문단에서 가져온다. 검색어가 걸린 본문 조각을 쓰지 않는다.
- 진행자가 주제에 자료 URL을 직접 넣으면 자동 검색을 하지 않고 그 URL에서
  가져온다. URL을 지우면 다시 자동 검색으로 돌아간다.
- URL에서 가져오는 것은 그 페이지의 메타 정보(og:title/og:description 등)
  추출이지, 내용을 읽고 요약하는 것이 아니다.
- 주제 전체 문구로 못 찾으면, 회의용 군더더기 말("확정", "검토", "다음" 등)을
  걷어낸 핵심어를 하나씩 다시 시도한다. 여러 단어를 합쳐서 재시도하지 않고
  긴 단어부터 한 단어씩 순서대로 시도한다.

## Boundaries

- 자료 출처를 다른 검색 서비스로 바꾸더라도 "제목이 맞는 것 하나, 없으면 없음"
  이라는 규칙은 유지한다.
- 회의 중 실시간으로 다시 찾지 않는다. 준비 단계에서 한 번 찾고, 진행자가
  다시 찾기를 눌렀을 때만 갱신한다.
- URL을 직접 넣는 기능은 내부망(localhost, 사설 IP 대역)을 가리키는 주소를
  걸러내지만, 그 이상의 SSRF 방어(리다이렉트 추적 검증, DNS 재바인딩 방어
  등)는 하지 않는다. 이 프로젝트의 검증 예산 밖이다.

## Why

전문 검색은 낱말이 본문 어딘가에 있기만 하면 걸린다. 회의 주제는 "기술 부채
정리", "배포 일정 확정"처럼 여러 낱말로 되어 있어서 낱말이 흩어져 들어간
문서가 잡힌다. 실제로 확인한 결과는 아래 증거에 있다.

제목 검색은 맞는 문서가 있으면 그것만 주고 없으면 아무것도 주지 않는다.
어설픈 자료를 세 건 붙이는 것보다, 맞는 것 하나를 붙이거나 없다고 말하는 편이
참석자가 자료를 신뢰하고 읽게 만든다.

## Reconsider when

- 핵심어로 재시도해도 빈손으로 끝나는 주제가 대부분이라, 자료를 붙인다는
  약속 자체가 무의미해진다.
- 자료 출처를 웹 검색 API로 바꿔 제목/본문 구분이 더 이상 의미가 없어진다.
- 군더더기 목록에 없는 회의 습관어가 계속 발견되어 목록을 관리하는 비용이
  검색 품질 향상보다 커진다.

## Still-rejected alternatives

- 전문 검색 결과를 세 건 보여주고 참석자가 고르게 하기 — 무관한 문서가 대부분
  이라 고를 것이 없었다. 자료를 읽지 않게 만든다.
- 전문 검색 결과의 첫 건만 보여주기 — 첫 건도 자주 틀렸다. "기술 부채 정리"의
  첫 건은 대한민국이었다.
- 핵심어 후보를 모두 합쳐 한 번에 재시도하기(예: "분기 로드맵") — 여러 단어를
  합친 구는 여전히 못 찾는 경우가 많았다. "고객 응대 매뉴얼"도 못 찾았다.
  한 단어씩 순서대로 시도하는 편이 hit율이 훨씬 높았다.

## Evidence worth preserving

주제 전체 문구 검색과 제목 검색을 비교한 결과다.

| 주제 | 전문 검색 | 제목 검색 |
| --- | --- | --- |
| 기술 부채 정리 | 대한민국, 남해회사, 뱅크런 | 기술 부채 |
| 스크럼 회고 | 스크럼 (프로젝트 관리), 플레이밍 스타, 엘비스 프레슬리 | 스크럼 (프로젝트 관리) |
| 마이크로서비스 전환 | 마이크로소프트, 마이크로소프트 오피스, 윈도우 업데이트 | 마이크로서비스 |
| 배포 일정 확정 | 근저당, 국민대학교, 이재명 | 없음 |
| 채용 진행 상황 | 김동연, G-TELP, 김승연 | 없음 |
| 다음 분기 로드맵 | 인텔 CPU 마이크로아키텍처 목록, 썬더코어, 노무현 | 없음 |

제목 검색이 빈손인 주제에 핵심어 재시도를 더한 결과다.

| 주제 | 제목 검색(전체 문구) | 핵심어 재시도 |
| --- | --- | --- |
| 배포 일정 확정 | 없음 | 배포 |
| 채용 진행 상황 | 없음 | 채용 |
| 다음 분기 로드맵 | 없음 | 로드맵 |
| 이번 주 예산 검토 | 없음 | 예산 |
| 신규 서버 도입 검토 | 없음 | 서버(도입은 시도하지 않음) |
| 분기 로드맵(핵심어 두 단어를 합쳐서 재시도) | 없음 | 없음(합쳐서 재시도하면 실패) |
| 고객 응대 매뉴얼(핵심어 두 단어를 합쳐서 재시도) | 없음 | 없음(합쳐서 재시도하면 실패) |

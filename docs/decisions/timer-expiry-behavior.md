# 타이머 종료 동작

## Decisions

- 배정 시간이 0에 도달해도 화면은 그 주제에 머문다. 자동으로 다음 주제로 넘어가지 않는다.
- 0 이후에는 초과 시간이 눈에 띄게 올라간다.
- 다음 주제로 넘기는 것은 진행자의 명시적인 조작으로만 일어난다.
- 결론이 비어 있어도 다음 주제로 넘어갈 수 있다. 도구가 진행을 막지 않는다.

## Boundaries

- 회의 전체 타이머에도 같은 규칙을 적용한다. 전체 시간이 소진돼도 회의를 자동으로 끝내지 않는다.
- 결론 입력을 강제하지 않는다는 뜻이지, 결론을 남기라고 알리지 않는다는 뜻은 아니다. 시각적으로 드러내는 방식은 이 결정의 범위 밖이다.

## Why

이 서비스가 약속하는 변화는 "타이머가 끝나기 전에 결론이 적힌다"이다. 자동 진행은 빈 결론을 조용히 통과시켜 그 압박을 없앤다. 반대로 결론 없이는 넘어가지 못하게 막으면, 다음 회의로 미루기로 한 주제에서 도구가 실제 회의를 막아선다. 머물면서 초과 시간을 드러내는 방식은 넘어가는 데 의식적인 동작을 요구해 압박은 남기되 회의를 막지는 않는다.

## Reconsider when

- 초과 시간이 표시돼도 빈 결론으로 넘어가는 일이 회의마다 반복된다.
- 진행자가 다음 주제로 넘기는 조작 자체를 부담스러워한다는 신호가 나온다.

## Still-rejected alternatives

- 결론 없이는 다음 주제로 이동 차단 — 다음 회의로 미루기로 한 주제에서 도구가 회의 진행을 막는다. 미루는 주제를 결론과 구분해 다룰 방법이 생기면 다시 볼 수 있다.
- 시간 종료 시 자동으로 다음 주제 이동 — 빈 결론이 조용히 통과되어 약속하는 변화를 밀어주지 못한다.
